## Sobre Mim

Olá! Me chamo **Daniel Santos**, sou **Engenheiro de Alimentos** formado pelo **Instituto Federal Baiano**, com atuação profissional em Engenharia de Software e desenvolvimento de soluções tecnológicas.

**Minha jornada em TI começou em 2021**, com o **Recode Pro**, programa de qualificação gratuita em programação que abriu as portas para minha transição de carreira para a tecnologia.

Desde então, venho aprofundando meus conhecimentos por meio de experiências profissionais, cursos e programas de formação. Fui bolsista do **CEPEDI**, no programa **Bolsa Futuro Digital**, com formação em Back-End com Python.

Também realizei uma **Pós-graduação em Engenharia de Software com Ênfase em Qualidade e Teste de Software**, pela Faculdade Anhanguera.

Atualmente, atuo como **Engenheiro de Software na Avatim**, desenvolvendo soluções voltadas à automação, integração de sistemas e controle de processos industriais.

Minha experiência abrange diferentes áreas da engenharia de software, incluindo desenvolvimento Full Stack, visão computacional, inteligência artificial, integração de hardware e software, sistemas embarcados e processamento de dados.

Tenho especial interesse em desenvolver soluções que conectem software, infraestrutura e equipamentos físicos, transformando desafios operacionais em sistemas automatizados e eficientes.

## Experiência & Projetos

### 🏭 Engenharia de Software | Avatim

Atuação no desenvolvimento de soluções para automação, integração de sistemas e controle de processos industriais.

- Desenvolvimento de aplicações e serviços utilizando C#/.NET.
- Desenvolvimento de aplicações mobile com React Native.
- Integração entre software, sistemas corporativos e equipamentos industriais.
- Comunicação serial utilizando RS-232 e RS-485.
- Integração com protocolos industriais Modbus RTU e Modbus TCP.
- Comunicação com equipamentos por meio de protocolos proprietários, incluindo soluções Toledo do Brasil.
- Aquisição, processamento e integração de dados para automatização de operações e processos produtivos.

**Tecnologias:** C#, .NET, React Native, Microsoft SQL Server, Modbus, RS-232, RS-485.

### 🔬 Visão Computacional | Inspeção Industrial

Desenvolvimento de soluções de visão computacional aplicadas à inspeção e identificação automática de não conformidades em processos industriais.

- Desenvolvimento de pipelines de processamento de imagens utilizando Python e OpenCV.
- Treinamento e utilização de modelos YOLO para detecção de não conformidades.
- Desenvolvimento de aplicações Android em Kotlin para aquisição de imagens.
- Interfaces web em React para monitoramento e acompanhamento dos processos.
- Integração entre dispositivos Android e ambientes Linux utilizando ADB, SCRCPY e V4L2.
- Containerização dos serviços com Docker.
- Implementação de rastreabilidade por meio de QR Codes.

**Tecnologias:** Python, OpenCV, YOLO, PyTorch, React, Kotlin, Docker, Linux, PostgreSQL.

### 🤖 Inteligência Artificial | Assistente Virtual

Desenvolvimento de assistente virtual com interação por voz e inteligência artificial para suporte a operações.

- Implementação de detecção de palavra-chave (Wake Word) com OpenWakeWord.
- Reconhecimento de fala utilizando Whisper.
- Síntese de voz com ElevenLabs.
- Integração com OpenAI API para processamento e consulta contextual a documentos.
- Autenticação biométrica por reconhecimento facial.
- Desenvolvimento de interfaces web para gerenciamento de usuários e conteúdos.

**Tecnologias:** Python, OpenWakeWord, Whisper, OpenAI API, ElevenLabs, React, Docker, OpenCV.

### 🐧 Sistemas Embarcados | Linux Customizado

Customização e otimização de sistemas operacionais Linux para hardware dedicado.

- Customização de sistemas Linux para equipamentos embarcados.
- Otimização de desempenho e redução do consumo de recursos.
- Gerenciamento de serviços utilizando Systemd.
- Redução do footprint do sistema operacional.
- Criação e clonagem de imagens de sistema com Clonezilla.

**Tecnologias:** Linux, Systemd, Shell Script, Clonezilla.

### 🌐 Desenvolvimento Full Stack | Sistemas Corporativos

Experiência no desenvolvimento e manutenção de aplicações web, microsserviços e sistemas corporativos em projetos de diferentes segmentos.
